# 充电功率（Android）

这是一个原生 Android 示例应用：读取系统公开的电池电流与电压数据，每秒估算一次电池端功率，并在应用界面和常驻通知中显示。

应用界面采用 iOS 26 风格的视觉方向：浅色半透明玻璃卡片、柔和的蓝紫氛围光、圆润分层与清晰的大号功率数字，并在主卡片内展示缓慢流动的液态波纹。动画仅在应用前台显示时运行。

## 在 Android Studio 中打开

1. 安装 Android Studio、JDK 17 和 Android SDK Platform 35。
2. 在 Android Studio 中打开本目录，等待 Gradle 同步完成。
3. 将手机连接到电脑并开启 USB 调试，选择设备后运行 `app`。
4. 首次使用点击“开始后台监测”，并允许通知权限；通知中的“停止”可以结束监测。

本项目未附带 Gradle Wrapper；Android Studio 可使用内置 Gradle 下载所需插件。

## 安装包

Debug APK 构建后位于 `app/build/outputs/apk/debug/app-debug.apk`，可复制到 Android 手机并打开安装。该包使用调试签名，仅适合本地测试和安装；正式发布前需要配置自己的发布签名。

## 读数与兼容性

- 估算公式：`功率(W) = |电池电流(µA)| × 电池电压(mV) ÷ 1,000,000,000`。
- 这是电池端功率估算，不是 USB 充电器的实际输出功率。电池管理芯片、系统采样频率、温控和设备实现都会影响读数；部分手机不开放实时电流数据，此时会显示“设备不支持读取”。
- 持续监测通过 Android 前台服务和常驻通知实现；电池数据采样在独立后台线程执行，避免占用界面线程。ColorOS/OPPO 的“流体云”是否接纳普通第三方应用通知，由具体机型、ColorOS 版本及系统策略决定；OPPO 未提供可供普通应用保证显示的通用公开接口，因此不能保证会出现在流体云。若系统不展示，可在系统设置中检查应用通知与后台运行权限。
- 通知标题显示估算瓦数，通知内容显示充电状态、电流和电压；流体云支持的设备可能会展示该持续通知。请在系统设置中允许“充电功率”的通知及后台运行，并检查流体云/通知管理中是否允许该应用显示。
- Android 14 及以上使用 `specialUse` 前台服务类型。若要通过 Google Play 发布，需要按 Play 前台服务政策声明并审核该用途。
